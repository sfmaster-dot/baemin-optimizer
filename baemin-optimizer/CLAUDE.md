# CLAUDE.md

This file provides guidance to Claude Code when working with code in this repository.

## Agent skills

### Issue tracker

Issues and PRDs live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles (`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`) used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
